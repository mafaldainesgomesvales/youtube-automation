Privacy Policy

Last updated: November 1, 2026

My YouTube Automation is a personal project used to create motivational YouTube Shorts.

Information and access

The project uses Google OAuth to request permission to upload videos to the owner's YouTube channel. It does not sell personal information or share it for advertising.

Data use and storage

OAuth credentials are stored as encrypted GitHub repository secrets. Generated videos and scripts may be stored temporarily as GitHub Actions artifacts.

Third-party services

The project uses Google, GitHub, and Pixabay services, which have their own privacy policies and terms.

Contact

For privacy questions, contact the project owner through the GitHub repository.
